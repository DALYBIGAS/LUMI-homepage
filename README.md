# DAPA homepage

The GitHub Pages entry now introduces DAPA, the personal assistant and agent
workspace. `index.html` is English; `zh.html` is Chinese. Both use `style.css`
and `app.js`. The interactive examples are browser-only illustrations and never
connect to a model, account, calendar or tool.

The previous LUMI research site remains at `research.html` and
`research-zh.html`, with its original assets, measured results and separate
styles/scripts. Keep research measurements separate from DAPA product claims.

This is a static site served from the repository root. No package installation,
build step, external font or analytics service is required. Preview with a local
HTTP server, then check both languages, mobile layout, keyboard tab navigation,
the mode selector, demonstration buttons, FAQ disclosure and research links.

DAPA is described as a development preview. Add installation links only when
verified public builds are actually available. Do not describe the connected
workspace as wholly offline; its configured providers and integrations have
their own network and data requirements.
